# Ανεμόμυλος Παλλήνης — web viewer

Περίπατος σε πρώτο πρόσωπο στην ερμηνευτική αναπαράσταση του ανεμόμυλου της Παλλήνης (three.js). WASD · Shift τρέξιμο · κλικ για έλεγχο.
